1. 연구 배경 & 목표

삼중음성유방암(TNBC)은 ER/PR/HER2 음성으로 표적치료제가 없으며, PD-1 억제제(pembrolizumab) 반응률이 ~20%에 불과해 반응 예측 바이오마커 발굴이 임상적으로 매우 중요하다.

Reference: Butner et al. (2023) Science Advances, adg0289
KEYNOTE-119 임상시험 데이터 기반 QSP 모델 (ORR ~20%)
  • 218-변수 ODE 시스템을 R로 구현
  • ODE stiffness 문제 해결 (quasi-SS 초기값)
  • Shiny App으로 interactive 시뮬레이션 환경 구축
  • RECIST v1.1 기반 치료 반응 평가 자동화

3. Key Equations

① 종양 성장 (Gompertz)

dC/dt = k_growth · C · ln(K_T / C_total) − k_kill · Tcyt · C / (C + K_C) − k_death · C
C: 암세포 수, K_T: carrying capacity, k_kill: CD8 살해율

② Carrying Capacity 동태

dK_T/dt = k_K_d · (K_target − K_T) K_target = C_total · (1 + f_vas · k_K_g/k_K_d)
VEGF 기반 혈관신생으로 K_T가 동적으로 증가

③ CD8 T세포 활성화 (LN)

daT_LN/dt = k_act · f_APC · p_j · nT1_LN − (k_pro + k_death) · aT_LN
f_APC: APC 활성화 분율, p_j: 항원 j 특이성

④ PD-1/PD-L1 차단 (Hill 함수)

f_block = 1 − [aPD1·PDL1] / (Kd·A + [aPD1·PDL1]) k_kill_eff = k_kill · (1 + E_max · f_block)
pembrolizumab가 PD-1:PD-L1 결합 억제 → 살해율 증가

⑤ 종양 부피 → 직경 (RECIST)

V_T = (C·v_c + T·v_T + M·v_M) / Ve_T · 10⁻¹² d_T = (6·V_T / π)^(1/3) [cm]
Ve_T=0.37 (공극률), SLD = d_T + Σ d_mets

10. 결론 & 향후 방향
1
218-변수 ODE TNBC QSP 모델을 R로 성공적으로 구현하고 수치 안정성(stiffness) 문제를 quasi-SS 초기값으로 해결
2
Pembrolizumab 200 mg q3w 시뮬레이션에서 BOR=PR (SLD −84.4%) 달성, 논문 ORR ~20% 범위 내에서 단일 환자 반응 재현
3
APC 밀도·Tcyt 분율 등 논문의 주요 바이오마커 cutoff를 모두 충족하는 반응자 프로파일 확인
4
Shiny 대시보드로 파라미터 조절·결과 시각화를 인터랙티브하게 구현, 임상적 의사결정 지원 도구로 활용 가능
향후 계획: 1,000명 가상환자(VP) 코호트 시뮬레이션으로 ORR ~20% 재현 검증 및 바이오마커 예측 모델 구축
